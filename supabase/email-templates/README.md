# Merchin auth email templates

Paste each into Supabase Dashboard → Authentication → Emails → Templates.

| Supabase template | Subject | File |
|---|---|---|
| Confirm signup | Confirm your Merchin account | `confirm-signup.html` |
| Invite user | You've been invited to join Merchin | `invite-user.html` |
| Magic Link | Your Merchin sign-in link | `magic-link.html` |
| Change Email Address | Confirm your new email address | `change-email.html` |
| Reset Password | Reset your Merchin password | `reset-password.html` |
| Reauthentication | Your Merchin verification code | `reauthentication.html` |
